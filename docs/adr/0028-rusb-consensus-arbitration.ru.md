# ADR 0028: rusb-strongs — консенсус-арбитраж Aquifer-reseat и russyn

## Статус

Принят (2026-10-16).

## Контекст

ADR 0027 дал перепосаженный слой с согласием 96.4–96.6 % с `russyn-strongs`
на идентичных стихах. Для движения к 99 % разобраны ~6 300 disjoint-позиций
(диагностика `(claimed_hit, aquifer_how, russyn_support)`):

- ~2 000 расхождений — **ошибки russyn, исправленные Aquifer**
  (`стал`→H1961 вместо H0216; `Бог`→H0430G; `не`→H3808): согласие с
  базой занижает реальную точность.
- ~2 300 — `lex/lex` неоднозначность: обе стороны правдоподобны.
- ~800 — позиции, где reseat оставил исходную (порочную) заявку Aquifer.

Монотонный DP (94.95 %), полные формы corpus-ru (92.7 % — шумные хвосты)
и бутстрэп-самообучение (−3.7 п.п.) опробованы и **отвергнуты**.

## Решение

`adjudicate_rusb.py` собирает развёртываемый слой как **консенсус** двух
независимых выравниваний на идентичных стихах (92 % всех стихов; совпадение
по токенам после `norm_ru`):

- согласие/пересечение → объединение кодов, `conf 10`, `consensus`;
- disjoint → **арбитраж** по взвешенным уликам: уровень поддержки в
  приорах (lex/stem/none), POS-совместимость (`lex.pos` кода ↔ грубая
  русская часть речи: aux-список + суффиксальные эвристики),
  `FUNC_RU_TO_CODES`, малый штраф за «немотивированную заявку Aquifer»,
  частотный тай-брейк. Итог: A 2 948 / R 1 754 / TIE 1 005
  (TIE → код Aquifer — всегда реальный mid стиха, `conf 8`).
- только-russyn → `russyn-fill` (conf min(russyn_conf, 9));
  только-Aquifer → `aq-only` (conf по способу посадки);
- неидентичные стихи → чистый перепосаженный Aquifer.

Два защитных правила stem-матча: **aux-слова не stem-матчатся**
(коллизия `пред` ~ `предал`→H5414).

Результат: 543 114 связей (покрытие union+fill ≈ russyn), согласие с
russyn на идентичных стихах **99.25 %**; остаточные 3 953 disjoint —
позиции, где слой осознанно берёт сторону Aquifer/TIE — выборочная
ручная проверка показывает, что большинство из них исправляет ошибки
russyn.

## Последствия

- Развёрнутый `rusb-strongs.sbz` — гибридный слой, не чистый Aquifer;
  `source='consensus'`, flags фиксируют класс решения
  (`consensus`/`arb-a`/`arb-r`/`arb-tie`/`russyn-fill`/`aq-only`).
- Ручная выборка ~70 арбитрованных случаев оценивает точность арбитра
  ≈ 90 % на конфликтах → точность слоя ≈ 99 % по независимой оценке.
- TIE-связи — «подброшенная монета» между двумя реальными кодами стиха:
  остаются conf 8, первые кандидаты на проход `strongs-review`.
- `corpus-ru` по-прежнему не питается: нужна метка редакции
  `rusb`/`russyn`.
