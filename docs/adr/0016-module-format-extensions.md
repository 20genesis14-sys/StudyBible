# 0016. Необязательные расширения формата модуля (до заморозки 1.0)

Статус: принято (05.10.2026).

## Контекст

Формат v1 (`docs/spec/05-module-format-v1.md`) хранит поток чтения.
Слова оригинала, подстрочник и критический аппарат сейчас лежат в
`spans.attrs` (`strong="…"`, `gr="…"`). В подстрочнике `int_en.sb` основной
текст — английская глосса, а греческое слово — атрибут: модель перевёрнута.
Критический аппарат и выравнивание хранить негде.

Условие пользователя: формат должен быть удобным на практике.
Конвертация чужих модулей (OSIS, USFM, Zefania, MyBible, BibleQuote, SWORD)
не должна быть трудной. Автор модуля не должен знать SQL.

## Решение

1. **Все расширения необязательны.** Модуль v1 без них остаётся правильным.
   Расширения не идут в `required`: старое приложение покажет текст и
   пропустит неизвестные таблицы (правило «Эволюция формата»).
2. **`meta.kind`** — тип модуля: `bible`, `interlinear`, `commentary`,
   `dictionary`, `layer` (слой без своего текста), `critical`.
   **`meta.features`** — список возможностей через запятую: `strongs`,
   `morph`, `tokens`, `alignment`, `variants`. Приложение строит лист «Слои»
   по `features`, а не по таблице в коде (`kModuleTags`).
3. **`tokens`** — слова оригинала: стих, порядок, форма, лемма, Стронг,
   морфология, глосса. Конвертер заполняет таблицу сам из того, что уже есть
   в источниках: OSIS `<w lemma morph>`, USFM `\w …|strong lemma x-morph\w*`,
   теги Стронга MyBible/BibleQuote. Отдельной работы от автора не нужно.
4. **`alignment`** — связь «токен оригинала ↔ слово перевода/глоссы».
   Вход для автора — простая таблица TSV: `ссылка  оригинал  глосса`
   (то же, что блоки «gloss / greek / pairs» в `build-interlinear.py`).
   Старый вид `gr="…"` читается дальше; конвертер переводит его в `tokens`.
5. **`variants` / `readings` / `witnesses`** — критический аппарат:
   место (стих + диапазон токенов), чтения, свидетели. Вход — TSV/JSON.
   Модуль-слой (`kind=layer`) может нести только аппарат без текста.
6. **`.sbz`** — контейнер для передачи: файл `.sb`, сжатый внешним
   кодеком. Внутри — обычная база SQLite. Приложение распаковывает файл
   при импорте. Заголовок: `magic "SBZ1"` (4 байта) + `codec_id` (1 байт)
   + payload. Кодеки: `0` = zstd (обязателен для читателя), `1` = brotli,
   `2` = xz (зарезервирован); прочие значения — на будущее, неизвестный
   кодек — понятная ошибка. Сжатие внутри базы — только для больших
   словарей и только через `required`.
7. **`entries`** — словарные статьи (модули `kind=dictionary`,
   06.10.2026). Плоская таблица: порядок `ord`, заголовок `headword`,
   нормализованная форма `norm` для поиска, текст статьи `text`.
   Модуль-словарь может не иметь книг и глав — `books` пустая,
   весь контент в `entries`. Вход автора — TSV `заголовок  текст`.
7б. **Инструменты для авторов.** `studybible module check` — проверка модуля
   с понятными сообщениями; `studybible module pack` — `.sb` → `.sbz`;
   шаблон TSV для подстрочника и аппарата; таблица соответствия полей
   чужих форматов в спецификации.

8. **Привязка сносок и ссылок к части стиха** (05.10.2026). Место span
   `f`/`x` в потоке сохраняется — относится и к сноскам, и к
   параллельным местам `x`. Необязательные поля: текст привязки
   (USFM `\fq`/`\xq`, OSIS `<catchWord>`) и буква части стиха (`\fr`/`\xo`,
   `1:1a`). Нет данных — ссылка к целому стиху; источники без позиции
   (MyBible, TSK) так и конвертируются.

9. **`meta.rights`** — флаги прав модуля (06.10.2026, закрывает вопрос
   № 15). Необязательный ключ, список запретов через запятую:
   `no-distribute` (не раздавать/не выкладывать), `no-net` (не отдавать
   по сети — web/API), `no-ai` (не передавать текст в ИИ-функции),
   `no-plugins` (не отдавать плагинам). Отсутствие ключа = всё разрешено.
   Это честное соглашение, не DRM; приложение уважает флаги в
   интерфейсе («поделиться файлом», экспорт, репозитории).

## Последствия

- Простой модуль делается как раньше: USFM/OSIS → конвертер → `.sb`.
- Подстрочник и аппарат — тоже из простых текстовых таблиц.
- Схема расширений замораживается вместе с форматом в 1.0.
