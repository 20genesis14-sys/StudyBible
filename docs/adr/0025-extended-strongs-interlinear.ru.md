# 0025. Расширенный лексикон Стронга, опорный слой оригинала, подстрочники и слои разметки

[English](0025-extended-strongs-interlinear.md) | **Русский**

Статус: принято (13.10.2026); реализация не начата. Полный план работ,
разбивка на задачи, перечень данных и описания скиллов — в спеке для
передачи работы [docs/strongs/HANDOFF.ru.md](../strongs/HANDOFF.ru.md).

## Контекст

Приложение поставляет классический словарь Стронга (openscriptures,
нумерация 1890-х) и показывает номера Стронга только там, где они есть
в модуле. Цели трека:

1. **Универсальный обновлённый лексикон Стронга** на открытых данных
   STEPBible (расширенные и уточнённые номера), сначала на английском,
   затем локализованный (сначала русский, потом любой язык).
2. **Подстрочники** на любом языке на основе того же лексикона.
3. **Разметка номерами Стронга переводов, где их нет**, в виде
   модулей-слоёв, которые накладываются на существующий перевод без
   распространения его текста (как «список номеров на стих» у AndBible).
4. **Наполнение мегаэнциклопедии** (ADR 0024) упоминаниями людей и мест с
   точностью до слова.

Что определило решение (проверено 12–13.10.2026):

- TAHOT/TAGNT размечают каждое слово (с разбивкой на морфемы)
  *уточнённым* номером (dStrong, например `H5414H`) и контекстным
  английским переводом; метка значения TAHOT (`to give:2_put;_set`) —
  это просто подзначение этого dStrong из TBESH (G→1, H→2, …).
  **Уточнённый номер уже и есть значение слова** — сопоставление со
  значениями BDB не нужно (нумерация BDB другая и не совпадает).
- Расширенные номера TBESH совпадают с номерами OpenScriptures в 9 289
  из 9 296; цепочка dStrong → eStrong → `AugIndex` → `LexicalIndex` →
  статья BDB проходит для 9 258 из 9 299.
- Колонка **Meaning** в TBESH основана на сокращённом BDB от Online
  Bible (© Larry Pierce); заголовок файла просит получить разрешение.
  Разрешение запрошено 13.10.2026 (ждём ответа). Краткие толкования,
  нумерация, транслитерация, морфология и связи — работа
  Tyndale/STEPBible под CC BY 4.0.
- Определения TBESG в диапазоне НЗ G1–G5624: Abbott-Smith
  (общественное достояние) — 5 607, STEPBible — 39; Middle Liddell
  (Perseus, вероятно CC BY-SA) — только 63 (+13 в G6000–6099). TFLSJ
  сделан из LSJ от Perseus (CC BY-SA 4.0).
- В греческом мало уточнённых номеров по значениям (292 с буквой в
  диапазоне НЗ); кандидаты для греческих значений — колонка
  «Sub-meaning» в TAGNT и домены Louw–Nida в MACULA.
- TTESV (теги STEPBible для ESV) — **CC BY-NC**; текст ESV защищён
  авторским правом. BSB tables (bereanbible.com) — CC0 с пословными
  связями с WLC/Nestle — независимый эталон. В USFM BSB от eBible номера
  сдвинуты (как эталон не годится).
- Clear-Bible/Alignments (CC BY 4.0) содержит ручные пословные
  разметки, в том числе Синодального (RUSSYN, ВЗ+НЗ, BiblioNexus 2024)
  и BSB; беглая проверка: 13–14 % размеченных русских «слов» RUSSYN —
  знаки препинания, Быт 1:2 не сходится — качество надо измерить до
  использования.

## Решение

1. **Набор модулей** (формат v1, необязательные таблицы по S-20):

   | Модуль | kind | Лицензия |
   |---|---|---|
   | `strongs-step` — универсальный лексикон | `dictionary` | CC BY 4.0 |
   | `strongs-step-<lang>` — языковой накладной модуль | `dictionary` | CC BY 4.0 |
   | `step-orig` — опорный слой оригинала (TAHOT/TAGNT) | `interlinear` | CC BY 4.0 |
   | подстрочник на языке | `interlinear` / накладной | CC BY 4.0 |
   | `<target>-strongs` — слой разметки одного перевода | `layer`, `features=strongs` | CC BY 4.0, или CC BY-NC, если во вход шёл TTESV |
   | `lsj` — полный LSJ (TFLSJ), по желанию | `dictionary` | вероятно CC BY-SA |

2. **Ключ лексикона — уточнённый номер** (`H5414H`); расширенный и
   классический номера — запасные ключи (`lex_base`). Морфемы `H9xxx` —
   тоже статьи. Определения лежат в отдельной таблице со **сменным
   источником** (`def_source`, `def_license`): по умолчанию — BDB от
   OpenScriptures для иврита, Abbott-Smith + STEPBible для греческого
   (76 статей ML в диапазоне НЗ заменяются); TBESH Meaning добавляется
   второй строкой, только если Online Bible даст разрешение —
   переключение не требует пересборки остального.
3. **Опорный слой** `step-orig`: каждое слово TAHOT/TAGNT с адресом
   (`Gen.1.1#03`), морфемами, уточнённым номером, леммой, морфологией,
   контекстным английским переводом, изданиями (NA/TR/Byz…, кетив/кре),
   ID человека/места, позже — номером слова MACULA. Нумерация `eng`.
4. **Подстрочники**: основной продукт — **словарный подстрочник**:
   краткое толкование уточнённого номера под каждым словом оригинала
   плюс строка морфологии (TEHMC/TEGMC). Для нового языка модель нужна
   только для перевода толкований и таблицы морфологии. Английский
   контекстный подстрочник (колонка перевода TAHOT/TAGNT) заменяет
   личный `int_en.sb`. Контекстный подстрочник на языке — по желанию,
   позже. Обратный подстрочник (перевод ↔ оригинал) строится из слоя
   разметки.
5. **Слой разметки** `<target>-strongs`: `links(book, chapter, verse,
   word, ref, strong, conf, flags, source)` в **нумерации стихов самого
   перевода** (индексы слов относятся к его тексту); привязка к
   переводу по `target_id`, `target_hash`, `tokenizer`. Применяется при
   чтении, только если совпали все три. Одно разбиение на слова в ядре
   (`studybible_core::text::words`, версия `w1`); инструменты получают
   слова только через `studybible tokenize`.
6. **Шкала уверенности 0–10** (`conf`) у каждого переведённого или
   размеченного элемента, с `flags` (причины), `review`
   (`auto|judge|human`), `source`. Уровни: 10–9 — принимается
   автоматически; 8 — принимается с пометкой; 7–6 — в приложении
   **«спорно»** (с альтернативой); 5 — ручная проверка, показывается как
   спорное; 3–4 — ручная проверка, по умолчанию скрыто; 0–2 — не
   публикуется. Балл складывается из независимых вариантов, обратного
   перевода, независимой модели-оценщика и правил; пороги подбираются
   на рабочих книгах, замораживаются до замера на отложенных, а
   **калибровка** (доля ошибок по уровням монотонна) — критерий
   приёмки.
7. **Конвейер разметки**: кандидаты без модели из опорного слоя стиха,
   отфильтрованные по изданию перевода → статистическое выравнивание
   (eflomal) → словарь соответствий → объединение; модель — только для
   нерешённых слов и строго из кандидатов стиха, в три прохода по
   главе: выравнивание → независимая проверка → сверка по главе
   (процесс подстрочника ASV от OpenBible). Шаги с моделью выполняются
   **агентом по главам**; для каждой главы сохраняется происхождение
   (модель и версия, версия правил, дата, баллы); прогон продолжается с
   места остановки. Эталон никогда не подаётся в промпт.
8. **Сначала английский, порог качества — до любого другого языка.**
   Эталоны: BSB tables и ручная разметка BSB от Clear (главные),
   собственная разметка KJV, TTESV по отложенным книгам, подстрочник ASV
   от OpenBible для сравнения. Отложенные книги (не входят во вход ни в
   каком виде): Руфь, Иона, Ездра, Пс 1–41, Ис 40–55, Марк, Филиппийцам,
   Иакова, Откр 1–5. Порог: F1 по значимым словам на отложенных книгах ≥
   согласие эталонов минус N пунктов (N фиксируется до прогона),
   точность уточнённого номера на именах ≥ 95 %, монотонная калибровка
   `conf`. Слова эталона, у которых нет слова оригинала в издании
   перевода, считаются **расхождениями исходных текстов** и в основную
   метрику не входят — 100 % совпадения не ожидается и невозможно.
9. **Правило для TTESV**: разрешён во входе (словарь соответствий)
   только по рабочим книгам; слои, где он использовался, помечаются
   CC BY-NC. Лексикон и опорный слой никогда не содержат данных из
   TTESV. Текст ESV — только для сверки и никогда не распространяется.
10. **Русский** (после порога): накладной лексикон (сначала краткие
    толкования и морфология; полные определения — после ответа Online
    Bible, переводятся один раз из выбранного источника), русский
    словарный подстрочник, слой разметки Синодального — из ручной
    разметки RUSSYN от Clear, если её подтвердит замер F, иначе
    конвейером; эталоны: RUSSYN от Clear (если годна), RST+ (после
    исправления импортёра MyBible), ru_rob.
11. **Наполнение мегаэнциклопедии** (этап 1 ADR 0024): ID людей и мест в
    TAHOT/TAGNT + TIPNR дают `verse_mentions` с точностью до слова,
    `relationships`, `entities`; OpenBible Geocoding — координаты;
    участники-референты MACULA — дополнительный источник упоминаний;
    локализованные `entity_names` — из слоёв разметки.
12. **Закрепление данных**: каждый внешний источник закреплён в
    `data/sources.json` (коммит + SHA-256) и скачивается
    `scripts/fetch-data.ps1` в `STUDYBIBLE_DATA/sources/strongs/`;
    производные модули сопровождаются атрибуцией STEPBible и списком
    наших изменений.

## Отклонённые варианты

- **KJV как опора разметки** (предложение AndBible): только
  классические номера, без значений, английский как посредник для
  других языков. Опора — слой оригинала.
- **Сопоставление значений STEPBible с номерами значений BDB**: системы
  разные по назначению и дробности; уточнённый номер уже кодирует
  значение.
- **Один модуль разметки на все переводы**: индекс слова осмыслен
  только для одного текста; универсальны лексикон и опорный слой,
  слой перевода остаётся тонким.
- **Полный LSJ внутри основного лексикона**: только греческий, ~32 МБ
  HTML, вероятно CC BY-SA, не переводится — остаётся отдельным модулем.

## Последствия

- Формат не меняется: новые модули используют существующие kind и
  необязательные таблицы; читателю добавляются наложение слоя, поиск по
  расширенным номерам и показ спорных мест.
- Нужны исправления приложения (отдельными коммитами): импортёр
  MyBible оставляет только последний из нескольких тегов `<S>` на слове
  (в RST+ теряют номер 6,8 % размеченных слов); `normalizeStrong` не
  принимает `H0029G` и формат unfoldingWord `G15100`; модуль BSB
  пересобрать из `bsb_tables.tsv`.
- Ответ Online Bible ничего не блокирует до перевода русских
  определений (фаза 8.1); без него используются определения по
  умолчанию.
- Основные затраты — проходы модели; словарный подстрочник для нового
  языка почти механический.
- ADR 0024 дополняется: `entities.strongs` хранит уточнённые номера.

## Дополнение 13.10.2026 — итоги фазы 1

Замеры A–G ([PROGRESS.ru.md](../strongs/PROGRESS.ru.md)) закрывают три
открытых места этого ADR:

- Пункт 10: ручная разметка RUSSYN от Clear в опубликованном виде
  непригодна (идентификаторы слов сдвинуты относительно списка слов) —
  слой Синодального строится конвейером; эталоны: RST+ (после
  исправления импортёра) и ru_rob.
- Греческие значения для подстрочника: домены Louw–Nida из MACULA (93 %
  слов НЗ) при условии проверки лицензии MARBLE; нумерованные значения
  TAGNT покрывают лишь 6 %.
- Потолок порога по значимым словам ≈ 95 % (BSB tables ↔ Clear BSB); при
  оценке номера форм Стронга в НЗ приводятся к номерам лемм, служебные
  слова считаются отдельно.
