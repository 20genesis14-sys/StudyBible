# 0019. Навигация: рабочее место, стек позиций, панели

Статус: принято (12.10.2026, решения пользователя). Реализация — в объёме 1.0
(вопрос № 21, «back-стек навигации»).

## Контекст

Переходы к месту Писания сегодня строят новый экземпляр экрана чтения
поверх стека Navigator: каждый экран — полная читалка со своими данными,
своим TTS-потенциалом и без общей истории переходов. Свайпы между главами
в истории не отражаются, шага «вперёд» нет, панели сравнения не вписываются
в модель «один Navigator на приложение». Пользователь зафиксировал главное
правило: внутренняя логика не дублируется по панелям и экземплярам —
TTS, история переходов, поиск и прочее единственны.

## Решение

### Уровни владения логикой

- **Приложение** владеет: голосовым движком TTS (один на процесс — всегда
  озвучивается одна позиция, второй озвучки не существует), полным журналом
  истории (бессрочный, существующий `history`), кэшем загруженных модулей.
- **Рабочее место** (`ReaderWorkspace`, объект данных вне дерева виджетов)
  владеет: стеком позиций и списком панелей. Экран чтения — только окно в
  рабочее место; второе рабочее место допустимо только для второго окна ОС
  (мульти-окно — отдельное позднее решение).
- **Панель** — представление позиции, а не копия читалки: у неё нет своего
  стека, истории и сервисов.

### Стек позиций (короткая память)

- Позиция — обобщённая запись `(kind, ref)` с расширяемым `kind`: стих
  `(module, book, chapter, verse)`, словарная статья, место комментария,
  аппарат и т. д. Позиция хранит **полный снимок панели**: модуль, слои,
  режим вёрстки/чтения.
- Записываются: свайпы через главу, прыжки по ссылкам, переходы из других
  экранов, смена перевода на том же месте. Прокрутка внутри главы — не
  переход; «место ухода» — текущий верхний стих. Прыжок на ту же позицию
  не пишется.
- «Назад»/«вперёд» шагают по стеку; новый переход обрезает хвост «вперёд».
  Лимит — 250 переходов. Стек персистентен между запусками: старт
  возвращает на место закрытия, «назад» шагает по прошлой сессии.
  Журнал истории — отдельно, без лимита; переход из журнала — вручную.
- Восстановление прокрутки — до стиха во всех режимах вёрстки.
- Системное «назад» (жест/кнопка Android): сначала закрывает открытые
  шторки и карточки, затем шагает по стеку, при пустом стеке — уход с
  экрана чтения; если читалка открыта как вкладка «Библия» — переход
  на Главную. Кнопок назад/вперёд в панели читалки нет — управление
  стеком через историю (ниже). Клавиши Alt+←/→ и кнопки мыши X1/X2 —
  позже.
- Старт приложения — на Главную (как сейчас); место закрытия доступно
  по «продолжить чтение», стек прошлой сессии восстанавливается в фоне
  и «назад» шагает по ней.
- Панель истории: пункт в меню «Ещё» читалки открывает компактную
  панель с шагами ‹ › по стеку; развёртывание открывает существующий
  экран «История».
- Шаг назад останавливает TTS.
- Экран «Сравнить» и карточка Стронга — поверхности, не позиции: в стек
  не пишутся, «назад» закрывает их; переход по ссылке из них пишет цель.

### Панели

- Одна главная панель владеет стеком и сервисами; дополнительные — по
  формуле от ширины/масштаба экрана (позже — ручная регулировка).
- Дополнительная панель по умолчанию синхронна с главной (`link_group`,
  ADR 0014) — в том числе через конверсию версификаций.
- «Лёгкое отцепление»: панель может показать любую позицию (другая
  глава/книга/перевод/словарь) независимо от главной. Переходы внутри
  отцепленной панели (тап по ссылке) остаются в ней и в стек не пишутся.
- Возврат в синхронный режим — логика есть (флаг следования); кнопка в
  интерфейсе — после релиза.
- TTS читает активную позицию главной панели; переключение источника
  озвучки на дополнительную панель предусмотрено архитектурно
  (TTS привязан к позиции, не к виджету), реализация — позже.

### Реализация

- Вариант А: стек в Dart-слое, `NavEntry` + указатель; системное «назад»
  через `PopScope` с динамическим `canPop` (Android predictive back).
- Внешние переходы (поиск, закладки, план, история) — команда
  `workspace.go(position)`; читалка единственна (`popUntil`/вкладка
  «Библия»), новых экранов чтения не создаётся.
- Пути эволюции без смены модели: собственные Pages внутри Navigator 2.0
  (официальный перехват back и predictive back) и Router/URL для веба.

## Последствия

- «Продолжить чтение» и восстановление сессии — бесплатно: рабочее место
  сериализуется в userdata.
- Раскладки, вкладки, разделение экрана — новые способы показать ту же
  модель; логика не трогается (основа кастомизации по ADR 0014).
- Тесты обязаны покрыть: перехват системного «назад» (жест и predictive
  back), обрезку «вперёд», персистентность стека, отцепление/синхронность
  панелей, остановку TTS на шаге назад.
