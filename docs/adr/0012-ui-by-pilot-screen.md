# 0012. Интерфейс выбирается по пробному экрану

Статус: принято, выбор не сделан.

## Контекст

Кандидаты — Slint и Flutter. У Slint вопрос лицензии для плагинов и риск AccessKit без rich text;
Flutter тяжелее и добавляет второй язык.

## Решение

Выбор — по пробному экрану: глава с абзацами, поэзией, заголовком, сноской и словами Иисуса;
выделение мышью и клавиатурой; смешанный иврит и русский; клик по слову; виртуализованная книга;
две панели с синхронной прокруткой; программа чтения с экрана; масштаб шрифта ОС.
Критерии: измеримые требования, доступность, bidi, локализация, лицензия.
Письмо в SixtyFPS — позже, если Slint останется кандидатом.

## Последствия

До выбора плагины не рисуют собственный интерфейс.
