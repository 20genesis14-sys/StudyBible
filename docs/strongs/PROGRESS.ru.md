## Фаза 1 — замеры (сделано 13.10.2026)

Запуск: `cd tools/strongs/measure && py -X utf8 <скрипт>.py` (каждый
1–4 мин; загрузчики — в `common.py`). Входы:
`STUDYBIBLE_DATA/sources/strongs/*`, USFM KJV `sources/eng-kjv2006`,
`modules/rstplus.sb`.

### A. Классический номер → уточнённый (`a_resolvability.py`)

Доля пар (стих, классический номер) эталона, которым в том же стихе
STEPBible соответствует ровно один уточнённый номер:

| Эталон | пар | однозначно | несколько | нет в стихе |
|---|---|---|---|---|
| BSB tables | 373 142 | 98,5 % | 0,4 % | 1,2 % |
| KJV | 310 076 | 95,8 % | 0,4 % | 3,8 % |
| ESV/TTESV | 338 533 | 96,3 % | 0,4 % | 3,4 % |

ВЗ однозначно 97,5–99,2 %, НЗ 90,6–96,8 %. **Вывод:** если у слова есть
классический номер, уточнённый определяется без модели примерно в
96–98 % случаев; «несколько» — редкость (H1121 «сын», H834, H1004,
H1697…).

### B. Согласие эталонов (`b_gold_agreement.py`) — потолок для порога

Пословно, один текст (BSB tables ↔ ручная BSB от Clear):

| Класс | слов | совпало |
|---|---|---|
| ВЗ, значимые | 271 539 | 95,2 % |
| НЗ, значимые | 82 436 | 95,4 % |
| ВЗ, служебные | 283 671 | 92,8 % |
| НЗ, служебные | 89 566 | 86,3 % |

Расхождения на служебных словах — в основном разница правил: BSB
tables ставят номер на каждое слово фразы («the heavens» → H8064 и на
«the»), Clear — только на главное. По стиху (доля номеров A в стихе B;
после фильтрации 163 072 внутренних кодов аффиксов Groves в
`macula_classic`): KJV↔ESV 97,8 / 89,6 %, BSB tables↔ESV 87,9 / 96,8 %,
BSB tables↔KJV 80,2 / 96,6 %, BSB tables↔Clear BSB 93,5 / **96,2 %**
(было 79,4 %), Clear BSB↔KJV **82,3 %** / 96,2 %, Clear BSB↔ESV
**89,2 %** / 95,6 %.
**Вывод:** потолок по значимым словам ≈ **95,2–95,4 %**; N порога
вычитается из этого числа (N ещё заморозить, вопрос 52). Служебные слова
оценивать по правилу, учитывающему соглашения (главное слово или вся
фраза), или отдельной строкой.

### C. Нумерация стихов (`c_versification.py`)

- TAHOT/TAGNT: 2 142 стиха с другой источниковой нумерацией (Псалмы —
  1 104). Полная карта выгружена в `work/strongs/measure/verse_map.json`.
- Состав стихов (eng): у STEPBible нет только 1 стиха (2Кор 13:14 —
  внутри 13:13 в TAGNT; Ин 7:53 и Рим 16:25–27 возвращены после починки
  скобок в `REF`); у BSB/KJV нет надписаний Псалмов как стиха 0
  (134/121); у ESV нет 18 стихов НЗ (Мф 17:21…).
- eng → rsc (через org, `data/versification/*.vrs`): номер меняют 2 816
  стихов; не один-к-одному только 10 (Неем 7:67, несколько надписаний
  Псалмов, Пс 87:1, 116:10, 147:12, Ис 63:19).
**Вывод:** существующий `Versification::convert` покрывает Синодальный;
10 случаев не один-к-одному — на проверку в `verse_map` в фазе 6.

### D. Исходные тексты и соглашения нумерации (`d_textual_basis.py`)

| Эталон | Завет | есть в своём издании | номер формы → лемма | только в другом издании | нет в стихе |
|---|---|---|---|---|---|
| BSB tables | ВЗ | 99,6 % | 0,0 | 0,0 | 0,3 % |
| BSB tables | НЗ | 96,7 % | 0,4 | 0,3 | 2,6 % |
| KJV | ВЗ | 99,0 % | 0,6 | 0,0 | 0,5 % |
| KJV | НЗ | 90,8 % | **5,9 %** | 0,0 | 3,3 % |
| ESV/TTESV | ВЗ | 98,1 % | 0,1 | 0,0 | 1,9 % |
| ESV/TTESV | НЗ | 92,7 % | 3,2 % | 0,8 % | 3,3 % |

**Выводы:** (1) настоящих расхождений изданий мало (≤ 0,8 %); (2) KJV и
TTESV в НЗ используют **номера форм** Стронга (G2076 «он есть», G5213
«вам», G2257 «наш»), а STEPBible — номера лемм (G1510, G4771,
G1473/G3165); TBESH/TBESG дают 315 таких связей, нужно больше (G2257,
G3450→G3165…); при оценке номера форм приводятся к леммам; (3) «нет в
стихе» у ESV — H4480 (1 987), H2088/H2009 — это особенности разметки
TTESV, ожидаемый шум эталона.

### E. Греческие значения (`e_greek_senses.py`)

- «Sub-meaning» в TAGNT заполнено у 100 % слов, но это в основном
  контекстный перевод формы («him / to him / of him»); настоящие
  нумерованные значения (`слово|1_значение`) — только у 6,2 % слов, 48
  лемм.
- Греческих уточнённых номеров с буквой — 6,3 % слов.
- Домен Louw–Nida в MACULA SBLGNT — у 93,1 % слов; у 1 522 из 4 972 лемм
  ≥ 2 доменов.
**Вывод (вопрос 51):** для греческого подстрочника по значениям нужны
домены Louw–Nida из MACULA (при условии проверки лицензии MARBLE,
вопрос 49); одного TAGNT мало. Иврит — значения TAHOT/TBESH (метка у
37 % слов).

### F. Ручные разметки Clear (`f_clear_alignments.py`)

- Согласованные наборы (≤ 0,1 % идентификаторов на пунктуации): eng BSB
  (покрытие WLCM 99,8 %, SBLGNT 99,6 %), eng YLT, arb AVD/ONAV, hin, spa
  RV09 (частичное покрытие 54–72 %), asm, ben, por, hau НЗ.
- **Сломаны:** rus RUSSYN (13–14 % идентификаторов на пунктуации), fra
  LSG НЗ (7 %), fra LSG ВЗ и hau ВЗ (идентификаторов нет в списке слов),
  eng BSB BGNT (не тот список слов).
- RUSSYN против RST+: номер MACULA совпадает с номером RST+ на указанном
  русском слове лишь в 39,4 % (ВЗ) / 38,7 % (НЗ) записей; правильное слово
  почти всегда на 1–6 позиций **раньше**; согласованы (≥ 90 %) лишь
  ~12–13 % стихов. JSON и TSV добавлены одним коммитом `6473aa4`
  (27.09.2024), значит идентификаторы получены на другом разбиении того
  же текста.
**Вывод (вопрос 50):** RUSSYN в опубликованном виде нельзя использовать
ни как эталон, ни как источник слоя Синодального. Синодальный идёт
через конвейер (фаза 8.3, эталоны — RST+ после исправления импортёра +
ru_rob). Возможный эксперимент на потом: перепроецировать записи RUSSYN
по порядку (монотонный сдвиг) и оставить только стихи, прошедшие
проверку.

### G. Слова MACULA ↔ TAHOT/TAGNT (`g_macula_step.py`)

| Завет | слов MACULA | по номеру | + по позиции в равных промежутках | всего |
|---|---|---|---|---|
| ВЗ | 305 517 | 97,2 % | 8 164 | **99,9 %** |
| НЗ | 137 741 | 91,9 % | 10 199 | **99,3 %** |

Промежутки в НЗ по номеру — это разница «номер формы / номер леммы»
(G2076, G5213…).
**Вывод:** данные MACULA (Louw–Nida, референты, разметки Clear)
привязываются к словам опорного слоя без модели.

## Решения по итогам фазы 1

1. Слой Синодального — конвейером, не из RUSSYN от Clear (вопрос 50
   закрыт).
2. Греческие значения — Louw–Nida из MACULA, если позволит лицензия
   (вопрос 51 закрыт, лицензионная часть остаётся в вопросе 49).
3. Потолок порога по значимым словам ≈ 95 % (BSB tables ↔ Clear BSB);
   при оценке номера форм НЗ приводятся к леммам, служебные слова
   считаются отдельно.
4. В фазе 6 по умолчанию — уточнение «классический → уточнённый» без
   модели (однозначно в 96–98,5 %).
