# Changelog

[English](CHANGELOG.md) | **Русский**

Все заметные изменения после релиза 1.0 — отдельными строками.

## 1.1.0 (не выпущена)

- Новая иконка приложения — раскрытая книга со светом на бордовом
  фоне; добавлена адаптивная иконка Android (foreground +
  бордовая подложка).
- Второй встроенный перевод: King James Version (1769, eBible.org)
  со Стронгом, параллельными местами и сносками — сидируется при
  первом запуске, как синодальный.
- Общий слой параллельных мест openbible-xrefs (ADR 0023):
  переводам без своих x-спанов подмешивается набор OpenBible при чтении;
  отключается в настройках; дубликат из модулей убран (russyn.sbz
  2,78 -> 1,74 МБ, kjv 8,2 -> 7,1 МБ).
- Исправлена web-сборка: в упакованных модулях не было декодера
  span_pack в веб-мосте (главы были без текста стихов).
- Формат модулей: блоб-упаковка `t`-спанов, токенов и alignment
  (ADR 0022, `meta.required="pack"`) — `.sb` модулей с разметкой
  заметно меньше; старые модули читаются как раньше, упакованные
  открываются только новым приложением.

- Исправлено: сетка глав на мгновение показывала фиктивную «1 главу»,
  пока модуль грузился — теперь до прихода документа крутится
  индикатор, счётчик показывает «…», полоса прогресса бежит.
- Быстрые карточки сносок и параллельных мест: тексты сносок
  прогреваются в фоне при открытии главы, ссылки грузятся параллельно,
  результаты кэшируются — повторный тап открывает карточку мгновенно.
- Скорость: соединение SQLite модуля открывается один раз за сессию
  вместо чтения всего .sb-файла при каждом запросе главы — заметно
  быстрее сноски, параллельные, листание и сравнение на десктопе
  и Android.
- Скорость: тексты уже вычитанных стихов запоминаются в модуле —
  соседние сноски на один стих не перечитывают его заново.
- Дизайн чтения: глава открывается крупной цифрой-буквицей в тексте
  (как в печатных изданиях); заголовок разбит на две строки — книга
  сверху, «Глава N» под ней.
- Новая настройка: насыщенность текста в четыре ступени (Обычный/
  Средний/Полужирный/Жирный) — в панели «Шрифт и тема» и в Настройках,
  с живым предпросмотром.
- Новая страница «Лицензии» в Настройках: список лицензий без дублей
  со ссылками на полные тексты, плюс полные тексты лицензий пакетов
  офлайн через встроенную страницу Flutter. Текст SIL OFL теперь
  поставляется вместе со встроенными шрифтами.
- Кандидаты шрифтов чтения: Lora, Alegreya, Source Serif 4,
  Roboto Serif, Charis SIL (полная кириллица, переменная
  насыщенность) и Paper Mono (только латиница); выбор шрифта —
  выпадающий список, где каждое имя показано своим начертанием,
  переменные шрифты получают точный `wght`.
- Исправлено: «выделение цветом» теперь закрашивает текст стиха,
  а не только номер (абзацный режим).
- Выделение теперь в шести цветах: жёлтый, зелёный, синий, розовый,
  фиолетовый, оранжевый.
- Можно выделять отдельные слова, а не только стихи целиком.
- Тап по выделенному — меню куска: другой цвет, заметка к фразе,
  снятие. Стронг — по долгому нажатию. В «Записях» — секция
  «Выделения»: одно действие — одна строка, удаляется целиком.
  В подстрочнике частичные выделения пока не красятся.
- Карточка сноски переделана: высота по содержимому (максимум
  75 % экрана, длинные — с прокруткой), текст сноски — читаемые
  15 pt.

## 1.0.1 (09.10.2026)

- Пользовательские записи: схема 2 — у заметки/закладки/выделения есть
  версификация модуля, идентичность модуля (content_hash) и контрольный
  фрагмент стиха; старые базы мигрируют автоматически.
- Перепривязка записей при обновлении модуля: переезд по контексту в
  соседний стих (±2), сироты в отчёте; запуск — при старте приложения,
  после импорта модуля и командой `user relink`.
- Кросс-переводные записи (этап А): у записи каноническая координата org;
  в окне своей заметки — кнопка «записи в других переводах»; тап по чужой
  записи открывает её стих в её переводе; вкладка «Записи» показывает все
  записи по переводам.
- Исправлено: модуль резолвится по `meta.id`, а не по имени файла —
  импортированный под «левым» именем модуль получал записи без меты
  и канона и был невидим для кросс-переводных записей и перепривязки.
- Импорт сохраняет файл как `<meta.id>.<ext>` — повторный импорт того
  же модуля перезаписывает, а не плодит копии.
- Исправлено: перепривязка доштамповывает канонический диапазон записям,
  у которых мета совпадает, но канон пуст.
- Порядок переводов в сравнении: выбранные модули переставляются
  стрелками — в листе выбора у строки сравнения и в настройках.
- Экспорт всех записей в Markdown: `studybible user export-md <файл.md>` —
  группировка по переводу и виду записей (только экспорт).
- Экран «Записи»: кнопки экспорта/импорта записей — меню экспорта
  в zip (перенос между устройствами, слияние «свежее побеждает»)
  и в Markdown (читаемый список, только экспорт).
- Экран «Записи»: секция «Потерянные» — записи, потерявшие привязку
  при обновлении модуля (сироты перепривязки), с текстом и удалением.
- Десктоп: Alt+←/→ и боковые кнопки мыши X1/X2 ходят по стеку
  переходов назад/вперёд, как в браузере.
- Внешние экраны читалки (Поиск, История, «Стих во всех переводах»)
  открываются как позиции рабочего места (kind='screen'), без нового
  маршрута: «назад»/Alt+←/X1 возвращают к стиху; переход к записи из
  списка чужих записей — тоже шаг стека, а не новый экран.
- Экран «Записи»: кнопка «поделиться» у заметки копирует её в буфер
  обмена в формате «Ссылка — текст (перевод)».
- Стрелка «назад» в шапке читалки ведёт строго вверх: глава →
  сетка глав книги. Назад по истории чтения — системным жестом.
- Поиск показывает число результатов: «Найдено: N» под полем
  запроса; при усечении лимитом — «Найдено: 100+».
- Исправлено (один из источников): параллельные места привязывались
  к маркерам по порядку и неверному номеру стиха-якоря — у стихов
  с двумя и более маркерами все после первого показывали пустую
  карточку или чужие ссылки. Теперь привязка прямая по id маркера.
