# StudyBible

Кроссплатформенное приложение для чтения и изучения Библии.

Две равноценные цели:

1. **Чтение** — простое, удобное, быстрое приложение.
2. **Изучение** — параллельные места, лексикон Стронга, сравнение переводов,
   подстрочники, оригиналы, комментарии.

Ядро пишется на Rust по схеме «порты и адаптеры», интерфейс заменяемый.
Данные пользователя хранятся только на его устройстве.

Статус: MVP, ядро и консоль. Интерфейса нет. Документация — [docs/SPEC.md](docs/SPEC.md),
ход работ — [docs/ROADMAP.md](docs/ROADMAP.md), открытое — [docs/OPEN-QUESTIONS.md](docs/OPEN-QUESTIONS.md).

## Структура

| Путь | Назначение |
|---|---|
| `crates/studybible-core` | Ядро: домен и порты |
| `crates/studybible-convert` | Конвертер форматов (библиотека) |
| `crates/studybible-store` | Модуль SQLite, поиск, данные пользователя |
| `apps/studybible-cli` | Консольная оболочка (`studybible`) |

## Поправка 2026-10-02

Исправления, без новых функций:

- KJV и WEB собираются с версификацией `eng`. В файлах eBible английская нумерация
  (Мал 4, Иоил 2:28). Метка `org` не открывала эти стихи ссылкой и развела бы сравнение.
- Ссылка на один стих в `read` и `say` — только этот стих. Глава без стиха и книга целиком
  по-прежнему читаются целиком.

Уже записано в решениях, в коде MVP этого ещё нет:

- конвертер OSIS;
- стемминг, фраза, NEAR, область поиска и поиск по нескольким модулям;
  конечные буквы иврита, маккеф и конечная сигма в нормализации;
- у порта «Речь» — пауза, скорость, голос, события фрагмента, числа и ссылки словами;
- в записи пользователя — версификация и версия модуля; консоль пишет пустой `context`;
- сегменты стихов (`1:1a`); флаги прав в метаданных модуля;
- замеры времён (глава, поиск, старт).
